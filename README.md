# ✅ Lista de Tarefas

Uma aplicação web desenvolvida para gerenciar tarefas de forma simples, intuitiva e eficiente. O projeto foi criado para praticar conceitos fundamentais de desenvolvimento Front-end, como manipulação do DOM, gerenciamento de estado e persistência de dados.

## ✨ Funcionalidades

* ➕ Adicionar novas tarefas
* ✏️ Editar tarefas existentes
* ✅ Marcar tarefas como concluídas
* 🗑️ Remover tarefas
* 💾 Persistência de dados utilizando LocalStorage
* 📱 Interface responsiva
* ⚡ Atualização dinâmica da interface
